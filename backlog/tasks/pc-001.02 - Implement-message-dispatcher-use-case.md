## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Create the message_dispatch use case in presence-cube.usecases/message_dispatch/. The dispatcher is a shared application service that dequeues raw payloads from the command queue, parses each as a JSON envelope ({ "type": "...", "data": { ... } }) using cJSON, and routes to the appropriate command handler based on the type field. Initially only "set_led" is supported. The dispatcher follows the existing handler lifecycle pattern (initialize/initialized/run/stop) and uses CException for error handling. It must be resilient — handler exceptions, unknown types, and malformed JSON are logged and discarded, never crashing the dispatch loop. The presence-cube.usecases/library.json must be updated to add dependencies on presence-cube.domain.queuing and cJSON.
<!-- SECTION:DESCRIPTION:END -->
