## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Create two ESP32-specific infrastructure libraries that implement the domain interfaces. The command queue (presence-cube.esp/command_queue/) uses FreeRTOS xQueue — xQueueCreate for init, xQueueSend (non-blocking) for enqueue, xQueueReceive (with timeout) for dequeue, vQueueDelete for destroy. The MQTT listener (presence-cube.esp/mqtt/) uses ESP-IDF esp_mqtt_client — connects to broker from Kconfig settings (CONFIG_ESP_MQTT_BROKER_URI), subscribes to the control topic (CONFIG_ESP_MQTT_CONTROL_TOPIC), and invokes the registered on_message callback with the payload on receipt. Both need library.json manifests.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 command_queue.c implements command_queue.h using FreeRTOS xQueue primitives
- [ ] #2 Enqueue is non-blocking and returns false when queue is full
- [ ] #3 Dequeue blocks up to the specified timeout and returns 0 on timeout
- [ ] #4 mqtt_message_listener.c implements message_listener.h using ESP-IDF esp_mqtt_client
- [ ] #5 Listener connects to the broker configured via Kconfig and subscribes to the control topic
- [ ] #6 On message receipt, the registered callback is invoked with payload and length
- [ ] #7 Both libraries have library.json manifests with appropriate dependencies
