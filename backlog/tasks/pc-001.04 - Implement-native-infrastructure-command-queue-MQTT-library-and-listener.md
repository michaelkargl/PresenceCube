## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Create the native-platform infrastructure for messaging. First, add a cross-platform C MQTT client library (e.g., Eclipse Paho MQTT C) as a submodule in lib/submodules/, following the existing pattern (cJSON, civetweb). Then create two native infrastructure libraries: the command queue (presence-cube.native/command_queue/) using a circular buffer with pthread mutex and condition variable, and the MQTT listener (presence-cube.native/mqtt/) using the MQTT client library to connect to a real broker. The native build is a functional replica of the embedded device — it connects to the same broker using CONFIG_ESP_MQTT_BROKER_URI and CONFIG_ESP_MQTT_CONTROL_TOPIC from sdkconfig.h.
<!-- SECTION:DESCRIPTION:END -->
