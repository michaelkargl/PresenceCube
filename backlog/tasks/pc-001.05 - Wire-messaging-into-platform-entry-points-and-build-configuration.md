## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Connect all messaging components in both platform entry points and update the build system. For ESP32: add CUBE_MQTT_ENABLED feature toggle (dependent on CUBE_WIFI_ENABLED) to main_esp32.c and wire initialization — command queue, message listener, topic subscription with enqueue callback, dispatcher initialization, start listener, start dispatcher on a dedicated FreeRTOS task. For native: add CONFIG_MQTT_ENABLED to sdkconfig.h and mirror the ESP32 wiring in main_native.c using a pthread for the dispatcher. Update platformio.ini lib_extra_dirs to include the new domain libraries (messaging, queuing) in the shared section and platform-specific libraries (command_queue, mqtt) in their respective sections.
<!-- SECTION:DESCRIPTION:END -->
